# Web 管理端

需要管理员启用并告知访问地址（用户向管理员索取）。页面路径固定在 `/web/` 下。

## 登录与准入

1. 打开 Web 管理端地址 → 未登录时自动跳到**飞书授权页**，授权后回到管理端。
2. 第一次登录的新用户状态为 **pending（待审批）**：所有页面都提示“已提交申请，等待管理员审批”或“没有权限”，同时管理员会收到飞书私信。**用户能做的只有等管理员在 `/web/admin` 同意**。被拒绝/撤销后同样无权限。
3. 只有 approved 用户可使用；会话用 Cookie 保持，过期需重新登录。
4. 快捷登录：在飞书里让 Agent 生成**一次性登录链接**（平台操作 `get_web_login_link`，5 分钟内有效、只能打开一次，身份是该 Task 的属主）。链接等同于登录凭证，只发给本人，不要转发。
5. 当前若通过 HTTP 访问，Cookie 与消息是明文传输，有被窃听风险；建议管理员尽快启用 HTTPS。

## 页面与功能

| 页面 | 功能 |
|---|---|
| `/web/` | 左侧 Task 列表（最新在上，滚动加载更多；状态 🟡idle 🟢running 🔴stop ⚫clear；可按状态/关键词/父子筛选）；右侧聊天窗，显示用户/Agent 消息（来源 🪶飞书 / 🌐web）、工具调用与结果（配对合并）、长内容截断；可发送消息，支持 `/steer` `/stop` `/esc`；顶部 Settings 管理该 Task 的环境变量 |
| `/web/ssh-key` | 本人的平台 SSH 公钥、指纹、创建时间；一键复制；“重新生成”（二次确认）；“在我的 Task 内使用私钥”开关；最近审计。详见 [ssh-key.md](ssh-key.md) |
| `/web/admin` | **仅管理员**：待审批列表、同意/拒绝、撤销、设置/取消管理员 |

- 普通用户只能看到自己的 Task；管理员能看到全部。不可见的 Task 与不存在的 Task 都显示为不存在。
- 从 Web 发的消息在飞书会话里的回复会带“回复 Web 消息：”前缀。
- Web 暂不支持 Timer 管理（请用飞书 `/timer`）。Web 里发 `/ssh` `/timer` 等会提示改用飞书/页面。
- 管理员不能撤销、降级或拒绝自己。

## 常见问题

- 登录后提示“没有权限”：多半在待审批，请联系管理员审批。
- 登录回调报错/跳转失败：属部署配置（飞书后台重定向 URL、`SUPAI_WEB_BASE_URL`），告诉管理员，不要自己改。
- 打不开页面：Web 服务需管理员启用（配置缺失时 Web 服务会自行不启动，其他服务不受影响）。
